# 📘 Capítulo 2: Naturaleza y ámbito de la empresa

---

## 🎯 Descripción del proyecto

Este recurso interactivo analiza en profundidad el **Capítulo 2** del libro de Estrategia Empresarial, que aborda la **naturaleza, los límites y el objetivo de la empresa** desde la perspectiva de la Nueva Economía Institucional (Coase, Williamson, Teoría de Agencia).

El contenido se aplica de manera práctica a la **industria textil en Chile**, utilizando ejemplos reales, datos de mercado actualizados (2025) y herramientas interactivas para comprender conceptos clave como:

- ✅ Costos de transacción (Coase, 1939)
- ✅ Especificidad de activos y hold-up (Williamson, 1985)
- ✅ Integración vertical vs. desintegración
- ✅ Problema de agencia (Jensen & Meckling, 1976)
- ✅ Límite vertical óptimo (I*)
- ✅ Determinación de gobernanzas (mercado, híbrido, jerarquía)
